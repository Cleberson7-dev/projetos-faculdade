# 🎓 Portal Universitário - Front-end

Projeto de interface web desenvolvido para a instituição de ensino UNINASSAU BOA VIAGEM, focado na apresentação da estrutura, da equipe (Respeita o comando) e navegação acadêmica do tema Educação.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica das páginas.
- **CSS3**: Estilização, layout e responsividade.
- **JavaScript** *(Em breve)*: Futura implementação de dinamismo e controle de navegação.
