## 🎓 Portal Universitário - Front-end

Projeto de interface web desenvolvido para a instituição de ensino UNINASSAU BOA VIAGEM, focado na apresentação da estrutura, da equipe (Respeita o comando) e navegação acadêmica do tema Educação, agora contando com interatividade dinâmica e conformidade total de acessibilidade.

## 🛠️ Tecnologias Utilizadas

HTML5: Estrutura semântica das páginas e atributos de acessibilidade (alt, marcações aria).

CSS3: Estilização, layout responsivo, regras de contraste e navegação por foco (:focus).

JavaScript: Lógica de dinamismo, manipuladores de eventos e renderização de novas abas de navegação.

VLibras: Integração do widget oficial para acessibilidade em Língua Brasileira de Sinais.

## ♿ Recursos de Acessibilidade (A11y)

VLibras: Widget integrado no topo da página para tradução de conteúdos digitais em Libras.

Navegação via Teclado: Borda destacada em amarelo vibrante (#ffcc00) em elementos focáveis (a:focus, button:focus).

Leitores de Tela: Imagens com atributos alt preenchidos e descritivos, alinhados à estrutura hierárquica (<h1>, <h2>, <h3>).

## ⚡ Funcionalidades Interativas

Plataforma de Estudos: Modal e aba interativa acionados via script para seleção de trilhas e cronogramas.

Painel de Concursos: Apresentação de vagas públicas (Banco do Brasil, SERPRO, TRT, PF, DATAPREV) dinamicamente geradas em nova aba.
